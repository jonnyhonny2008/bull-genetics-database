BS

Bull Stud Genetics Intelligence Platform

Phase 1 — Historical Genetic Proof Database · deployable package index

What this is

A private, role-based web app for a bull stud: historical genetic proofs, milk & classification records, source tracking with a preferred-value engine, uploads/review workflow, animal profiles, search, comparison, a Lactanet bull-proof CSV importer, a Holstein.ca paste importer for females, and a proof-style linear conformation graph. Runs as two isolated environments on one codebase — a seeded DEMO and a clean PRODUCTION.

Quick start (deploy / run)

# prerequisites: Node.js 18+ (built & verified on Node 20.18)
npm install

# DEMO — seeded sample data, http://localhost:3000
npm run setup:demo
npm run dev:demo        # or: npm run build && npm run start:demo

# PRODUCTION — clean (config only, no fake animals), http://localhost:3100
npm run setup:prod
npm run build
npm run start:prod

Default admin login (both environments): admin@studgenetics.local / Admin#12345 — change it before real production use (see docs/GO-LIVE.md).

Notes for deployment

  • Stack: Next.js 14 + Prisma 5 + SQLite (swap to PostgreSQL via prisma/schema.prisma + DATABASE_URL).
  • Environment vars per env: APP_ENV, DATABASE_URL, SESSION_SECRET, UPLOAD_DIR, IMPORTS_DIR.
  • Drop large Lactanet proof CSVs into imports/ (not bundled — see imports/README.txt).
  • This index.html is documentation only; the running app is served by Next.js from src/app.
